# Tsunami Codebase Overview and Next Steps

## Project Summary
This is the **Tsunami** framework - a React-like VDOM system implemented in Go that renders to a TypeScript/React frontend. It's part of the Wave Terminal project (waveterm).

## Architecture Highlights

### Core Packages
- **tsunami/vdom/** - VDomElem, VDomFunc, VDomRef types and H() function for creating elements
- **tsunami/engine/** - ComponentImpl, RootElem, rendering, hooks, effect management
- **tsunami/app/** - Public API (DefineComponent, UseLocal, UseTermRef, etc.)
- **tsunami/frontend/src/** - React renderer that consumes Go-generated VDOM via SSE

### Key Components
1. **VDomElem** - Virtual DOM elements with waveid tracking for reconciliation
2. **ComponentImpl** - Persistent component tree with hooks and atom dependencies
3. **Atoms** - Four types: $local. (component-local), $shared., $data., $config. (persistent)
4. **Hooks** - UseLocal, UseRef, UseId, UseRenderTs, UseResync, UseEffect, UseGoRoutine, UseTicker, UseAfter

### Communication Flow
1. Go backend defines components via `app.DefineComponent()`
2. Frontend makes HTTP requests to `/api/render` with events/state
3. Backend responds with VDomBackendUpdate containing rendered VDOM
4. SSE events handle async updates, modals, terminal writes

## Available Demo Apps

- pomodoro - Pomodoro timer with UseTicker/UseAfter
- cpuchart - Chart rendering with Recharts
